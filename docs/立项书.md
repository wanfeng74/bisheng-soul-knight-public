## 一、项目背景

### 1.1 平台背景

本项目运行在有道词典笔的 **Falcon / POSC 小程序运行时**上，属于「小屏 + 弱性能 + 受限运行时」场景：

- 逻辑宽固定 **960**，逻辑高按设备物理比例换算（实测区间约 **240～576**，设计基准 266）；
- 运行 **QuickJS 20200705**（`ui/package.json` → `quickjs.version`），只保证 ES5 语法子集；
- Canvas 2D 能力受限：无 `arc` / `strokeRect` / `beginPath` / 渐变 / `textBaseline`；
- 页面上下文**没有** `window` / `document` / `requestAnimationFrame`，循环只能用 `setInterval(16ms)`；
- 原生能力（存储、音频、更新）只能经 `jsapi` / `native-mods.js` 获取，静态 `import` 缺失会整页白屏。

### 1.2 技术底座来源

上一代已验证项目「**三角洲摸金模拟器**」在同一运行时上跑通了：

- Vue 2 SFC 子集 + Canvas 2D + QuickJS 的工程结构；
- 960 逻辑宽 + `pageH` 的屏幕适配体系；
- 三平台（rk / cvis / rka）单包构建、家族组合包、自动更新链路；
- 存档（`jsapi.storage`）、音效（原生 GStreamer）、日志与黑屏防护经验。

本作**不重写底座**，直接继承其构建脚本、适配方案与运行时红线（见 [docs/技术规范/](技术规范/)），把精力集中在「2D 俯视像素地牢射击」的玩法实现上。

### 1.3 玩法对标

玩法对标凉屋游戏《元气骑士》（Soul Knight）的核心循环：

```
大厅选角 / 升级 → 进入地牢 → 逐房间清怪 / 开箱 / 商店 → Boss → 三选一天赋 → 下一层
→ 第 6 层终局 Boss → 结算（宝石 / 成就 / 记录）→ 回大厅继续成长
```

本项目是**同人练习作**，不复刻原作美术与音频素材，所有像素图与音效均由本项目自绘 / 程序生成；角色与武器名称属于对同类玩法的致敬命名。

## 二、项目目标

### 2.1 总目标

在词典笔小屏上做出**可完整通关**的《元气骑士》式 2D 俯视像素地牢射击：

1. **玩法闭环完整**：选角 → 地牢 → Boss → 结算 → 成长，单局可从头玩到尾；
2. **还原度 ≥ 90**：按 [还原度验收.md](还原度验收.md) 的 60 项检查表加权评分（满分 100），当前自评分与缺口必须如实公示；
3. **三平台可安装**：rk / cvis / rka 各出可安装的 `.amr` 单包（真机验证状态单独标注）；
4. **稳定性优先**：不白屏、不黑屏、不卡死；异常路径有降级（存储失败退内存、音频缺失静默、缺 sprite 用占位块）。

### 2.2 体验目标（设计值，待真机验证）

| 指标 | 目标值 | 说明 |
|---|---|---|
| 单局时长 | 8～15 分钟 | 6 层，每层 6～8 房间 |
| 单房间战斗 | 15～40 秒 | 视房间类型与精英怪而定 |
| 操作方式 | 虚拟摇杆 + 按钮 | 左手移动、右手开火/技能/换枪/交互 |
| 失败成本 | 可接受 | 死亡可用宝石复活（`reviveCost = 5 + 层数×2`），不复活则结算 |
| 成长节奏 | 每 1～2 局解锁 1 名角色 | 角色解锁价 500～3000 宝石 |

> 以上为设计目标，实际手感需真机调参；文档中凡未经真机确认的数值均会注明「待真机验证」。

### 2.3 量化交付目标

## 三、范围与非目标

### 3.1 本期范围（In Scope）

- **纯单机**：所有玩法逻辑在本地完成，无服务器依赖、无账号体系；
- **8 名角色**：骑士 / 游侠 / 法师 / 精灵 / 工程师 / 刺客 / 炼金术士 / 圣骑士（id 固定为 `knight/rogue/wizard/elf/engineer/assassin/alchemist/paladin`）；
- **局内成长**：金币拾取、武器拾取与切换、天赋三选一、护甲/能量回复；
- **局外成长**：宝石结算、角色解锁、6 项永久升级（生命/护甲/能量/暴击/移速/冷却，各 0～5 级）；
- **地牢**：3 章（森林遗迹 / 沙海地宫 / 霜寒王座）共 6 层，含战斗/精英/宝箱/商店/雕像/Boss 房间；
- **局内设施**：商店买卖、宝箱、雕像（祝福）、传送门、可破坏的木箱木桶；
- **死亡与复活**：宝石复活（费用随层数递增）、拒绝复活后结算；
- **Meta**：结算页、最佳记录、成就、图鉴（武器/敌人/成就三 tab）、设置（音效/自动瞄准/震屏/FPS）；
- **表现**：自绘像素精灵（程序生成 PNG）、程序合成 WAV 音频、伤害数字、屏幕震动、命中反馈；
- **工程**：三平台构建脚本、存档、日志、静态检查与自动化测试。

### 3.2 非目标（Out of Scope，本期不做）

| 非目标 | 说明 |
|---|---|
| 联机 / 合作 / 对战 | 纯单机，无网络同步 |
| 内购 / 广告 / 付费点 | 宝石只能靠通关与成就获得，无充值入口 |
| 服务端账号 / 云存档 / 排行榜 | 排行榜只做**本地记录**（`save.js` 的 `stats`） |
| 在线自动更新服务 | 继承旧项目的更新**技术规范**仅作参考，本作不搭建更新服务器；发版走侧载安装 |
| 自定义键位 / 手柄 / 体感 | 只做屏幕虚拟按键 |
| MOD / 关卡编辑器 / UGC | 不开放内容制作 |
| 多语言 | 仅简体中文 |
| 与官方任何形式的合作或授权 | 本项目与凉屋游戏无关 |

### 3.3 明确的取舍

- **不做真人动作/物理引擎**：碰撞用圆-矩形近似，弹道用直线+寿命，不引入物理库；
- **不做离屏 canvas**：静态地图用 `createImageData/putImageData`，失败则退回逐格绘制；
- **不做高清美术**：像素精灵 12×16 / 14×14 / 28×32，靠配色与轮廓区分；
- **不做大量同屏特效**：粒子上限受控（目标 ≤ 80 个），保证低端 armv7 设备帧率。

## 四、技术底座

### 4.1 运行时与语言

| 项 | 约定 |
|---|---|
| 运行时 | Falcon / POSC 小程序（`$falcon` 全局） |
| JS 引擎 | QuickJS `20200705`，`bigNum: false` |
| 语法 | **ES5 风格**：`var` / `function` / 原型；禁止箭头函数、模板字符串、`let/const`、解构、可选链、`Array.includes`、`Object.assign` |
| 页面框架 | Vue 2 SFC 子集（单类名选择器、`border-radius` 单值、生命周期钩子写在 `methods`） |
| 渲染 | Canvas 2D 受限指令集（`fillRect/fillText/save/restore/translate/rotate/scale/setTransform/globalAlpha/fillStyle`） |
| 主循环 | 页面托管 `setInterval(16ms)`，禁止 `requestAnimationFrame` |
| 打包 | `single-js-bundle: true`（`ui/package.json`） |

### 4.2 适配方案

- `app.js` 调 `setViewPort(960)`，1 逻辑 px = 物理宽 / 960；
- 逻辑高 `pageH = round(960 × 物理短边 / 物理长边)`（`services/screen.js`），下限兜底 120；
- 页面布局用 `vw/vh`（宽度用 vw，纵向用 vh），游戏 canvas 按物理像素设置后备缓冲；
- 详见 [屏幕适配.md](屏幕适配.md)。

### 4.3 工程结构

```
ui/                客户端源码（Vue 2 SFC 子集 + Canvas 2D + QuickJS）
  src/app.js       应用入口（全局状态、setViewPort、日志、音效）
  src/pages/       6 个页面（index/game/result/characters/codex/settings）
  src/services/    存档 / 屏幕 / 音频 / 日志 / 原生模块
  src/services/game/  游戏数据与引擎（constants/rng/palette/characters/.../engine）
  src/res/version.js  构建生成物（禁止手改）
scripts/           构建、打包、版本生成（Node 24 ESM）
tools/             精灵 PNG / 音频生成、静态检查器
native/            三平台原生库源码与构建
rk/ cvis/ rka/     各平台构建产物
docs/              文档（本目录）
```

### 4.4 构建链

- 打包前端：**Node 16** 跑 `aiot-vue-cli`（Node 17+ 报 `No such module: http_parser`）；
- 构建编排：**Node 24** 跑 `scripts/build-amr.mjs`（项目根，ESM）；
- 三平台 profile 见 `scripts/profiles.mjs`：rk=arm64/glibc，cvis=armv7/glibc，rka=armv7/uClibc；
- 版本唯一入口 `ui/package.json` 的 `version`（当前 `0.1.0`），`res/version.js` 由 `scripts/gen-ui-version.mjs` 生成；
- amr 包体目标：组合包 < 10MB，音频总计 < 2.5MB。

### 4.5 存储与音频

- 存档：`ui/src/services/save.js`，单存档整体写入，键 `sk_save_v1`，多后端兼容（jsapi-storage / jsapi-item / native / localStorage），全部失败退内存；
- 音频：`ui/src/services/sound.js`，经 `updater.audio` 播放安装包内 `assets/sounds/*.wav`，无原生能力时静默降级。
