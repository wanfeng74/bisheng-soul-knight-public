# 笔上元气骑士 · 开发规范

> 版本：v0.1（2026-10-26）
> 适用：`ui/src/**`、`tools/**`、`scripts/**`、`native/**`
> 上位文档：[架构与接口.md](架构与接口.md)（唯一接口来源）。本文与旧项目 `docs/技术规范/开发规范.md` 冲突时，**以本文 + 架构与接口.md 为准**。

---

## 一、基本原则

1. **先查契约再动代码**：字段名、数据结构、模块边界以 [架构与接口.md](架构与接口.md) 为准；要改接口，先改契约并通知 Lead，禁止单方面改字段。
2. **不越界**：只改自己归属的文件（见第七节）；跨文件需求先发消息说明。
3. **稳定性 > 功能**：词典笔是真机设备，白屏/黑屏/卡死比少一个功能严重得多。所有新增能力必须有降级路径。
4. **中文**：文档、注释、UI 文案、日志、提交说明一律中文。
5. **数字可核对**：文档里的数值必须能从代码或构建脚本查到；不确定的写「待真机验证」。

## 二、版本与生成物

- **唯一版本入口**：`ui/package.json` 的 `version`（当前 `0.1.0`）与 `appid`（当前 `8001865309001001`）。
- `ui/src/res/version.js` 由 `scripts/gen-ui-version.mjs` 生成，**禁止手改**；构建前会按目标重写，构建结束恢复 rk 默认值。
- 生成物清单（不要手改、不要提交中间态）：
  - `ui/src/res/version.js`
  - `ui/src/services/native-mods.js`（由 `scripts/native-mods-content.mjs` 生成）
  - `ui/libs/`（构建暂存目录，单包平铺 / 组合包按代号子目录）
- `buildCode = 主×10000 + 次×100 + 修`：`0.1.0` → `100`；`1.1.52` → `10152`。
- 发版递增：`node scripts/build-amr.mjs --release`（自动 patch +1）。
- **注意**：仓库里 `ui/src/res/version.js` 与 `rk/*.amr` 可能仍是旧项目残留值（如 `1.1.357` / `8001865309000007`），以构建重新生成后的值为准；发现不一致时不要手改生成物，重新构建。

## 三、运行时红线（会白屏 / 黑屏）

### 3.1 语言

1. `ui/src/services/game/**`（含数据与美术模块）**一律 ES5 风格**：
   - 只用 `var` / `function` / 原型；
   - 禁止箭头函数、模板字符串、`let/const`、解构、可选链、`Array.prototype.includes`、`Object.assign`、`Map/Set`。
2. 页面与应用入口沿用旧项目已验证写法（`app.js` / `base-page.js` 使用 `const`/`class`），**不要把新语法带进 game 目录**。
3. 页面生命周期钩子必须写在 `methods` 里；`onShow` / `onHide` 内逻辑各自独立 `try/catch`。
4. 不写 `window` / `document` / `require` 业务逻辑：
   - 页面上下文通常没有 `window` / `document`；`require` 只能经 `services/native-mods.js` / `optional-native.js`；
   - 静态 `import 'panet'` / `'Eric'` 只允许出现在 `native-mods.js`（由构建按目标生成），否则缺库时整页白屏。
5. 游戏循环用页面托管的 `setInterval(16ms)`；**禁止 `requestAnimationFrame`**。
6. 熄屏/切后台：读 `$falcon.__gameHidden`（`app.js` 写入），不能只依赖页面 `onHide`。
7. 定时器必须可释放：页面用 `BasePage` 的 `setTimeout/setInterval`，`onUnload` 统一清理。
8. 不在客户端写服务器地址/密钥；本作**纯单机**。

### 3.2 Canvas

只允许：

```
fillRect  fillText  save  restore  translate  rotate  scale  setTransform
globalAlpha  fillStyle  createImageData  putImageData
```

禁止：`arc` / `strokeRect` / `beginPath` / `lineTo` / `closePath` / `createLinearGradient` / `createRadialGradient` / `textBaseline` / `drawImage`（无 `Image` 对象）。
圆角、圆形用像素块拼；静态地图若用 `createImageData` 必须先做能力探测并 fallback 到逐格绘制。

### 3.3 原生能力

- 原生模块统一从 `services/native-mods.js`（静态，构建生成）或 `services/optional-native.js` 的 `tryRequire()`（运行期）获取。
- `.vue` 的 `<script>` 内**不要写 `require(...)`**：构建器会把它提升为顶层静态 import，真机缺库即黑屏（旧项目 v1.0.55 事故根因）。
- 原生函数调用遵守 QuickJS 限制：不要对原生函数用 `.apply()` / `.call()`。

## 四、页面规范（Vue 2 SFC 子集）

1. **CSS 选择器**：只支持单类名，禁止 `.a.b` 复合选择器；动态样式用 `:class` 切多个独立类名。
2. **`border-radius` 只支持单值**，禁止 `6px 6px 0 0`。
3. 模板里用到的 class **必须有样式**（`tools/check-css-classes.mjs` 会查）。
4. 可能为 `null` 的数据用 `v-if` 渲染，不要用 `v-show`（`tools/check-vshow-null.mjs`）。
5. 尺寸用 `vw` / `vh`，根容器 `100vw × 100vh`；不要写死 266 或按 `pageH - 常量` 算 px（见[屏幕适配.md](屏幕适配.md)）。
6. 页面导航：`$falcon.navTo(page, options)`；返回/关闭：`this.$page.finish()`。
7. 页面间只通过 `$falcon.__gameRun` / `$falcon.__gameResult` / `$falcon.__gameDb` 传数据；**结算数据以 game 页写入为准，结算页只读**。
8. `onShow` 内所有逻辑独立 `try/catch`；不要留未清理的订阅与定时器。
9. 页面只做 UI 与事件绑定，游戏数值一律来自 `engine.getHud()` / 存档，**页面不自行计算战斗数值**。

## 五、存档规范

- 统一使用 `ui/src/services/save.js`，不要直接读 `jsapi.storage`：
  - `load()` → `Promise<db>`，内部已 `normalize` 并缓存到 `$falcon.__gameDb`；
  - `save(db)` → `Promise<bool>`，整体写入，自动写 `saveAt`；
  - `reset()` / `clearSave()`、`persistAvailable()`、`storageKind()`。
- 存档键：`sk_save_v1`；版本字段 `v: 1`。**加字段必须同步改 `defaultSave()` 与 `normalize()`**，保证旧档可升级、坏档可修复。
- 存档结构以 `defaultSave()` 为准；`charUpgrades` 每项 0～5，`stats` / `settings` 不可为 `null`。
- 写失败要有降级：`save.js` 已在多后端失败时退内存（可玩但丢进度），页面不得因写失败崩溃。
- 重要节点写档：开局参数、结算（`applyRunResult` 后）、解锁角色/升级、设置变更、关闭游戏前。
- 重置存档必须二次确认（设置页）。

## 六、数据模块规范

- 目录：`ui/src/services/game/`（数据）与 `ui/src/services/game/sprites/`（美术）。
- 模块风格：ES5 + ESM `export var` / `export function`（便于 Node 测试 import）。
- id 统一 `lower_snake_case` 且全局唯一；`sprite` 字段命名：
  - 角色 `player_<id>`、敌人 `enemy_<id>`、Boss `boss_<id>`、武器 `wp_<id>`、拾取物 `pk_<id>`、道具 `prop_<id>`、UI `ui_<name>`。
- 依赖限制：数据模块只 import 同目录的 `constants.js` / `rng.js` / `palette.js` 及契约允许的模块；**不要 import 页面/引擎/原生模块**。
- 随机必须走 `rng.js`（可复现）：地牢、掉落、商店都用同一 seed，测试才能断言。
- 数值边界（以契约与 `constants.js` 为准）：
  - 设计分辨率 `TILE=32`、`DESIGN_W=960`、`DESIGN_H=266`；
  - 角色/武器/敌人数值见 [GDD.md](GDD.md)；
  - 复活费用 `reviveCost(floorIndex) = 5 + max(1, floorIndex) × 2`（`constants.js`）。
- 新增数据必须同时补测试：`ui/scripts/test-content.mjs` / `test-dungeon.mjs` 由对应归属人维护，其他测试归 qa-docs/Lead。

## 八、构建

### 8.1 环境

- 打包前端必须 **Node 16**（`aiot-vue-cli` 依赖旧 webpack-dev-server，Node 17+ 报 `No such module: http_parser`）；
- 构建编排用 **Node 24**（DSH 自带运行时）；
- 依赖：`ui/node_modules` 已安装（`pnpm-lock.yaml` 固定）。

本机 Node 16 便携路径（旧项目实测，沿用）：

```
D:\wangshibo\tools\node-v16.20.2-win-x64
```

### 8.2 命令（项目根执行）

```powershell
# 只打 rk 单包（最快自测）
$env:PATH="D:\wangshibo\tools\node-v16.20.2-win-x64;$env:PATH"
$env:PNPM_CMD='cd /d "D:\wangshibo\project1\笔上元气骑士\ui" && "D:\wangshibo\tools\node-v16.20.2-win-x64\node.exe" "node_modules\aiot-vue-cli\src\cli.js" -c -q -p'
node scripts/build-amr.mjs --targets rk

# 三平台单包
node scripts/build-amr.mjs

# 指定目标 / 验证构建 / 发版递增
node scripts/build-amr.mjs --targets rk,cvis --verify
node scripts/build-amr.mjs --release --targets rk

# 只暂存库不打包
node scripts/build-amr.mjs --stage rk

# 家族组合包（默认 cvis + rka；本作暂不需要）
node scripts/build-amr.mjs --merge
```

### 8.3 约束

- 三平台 profile 见 `scripts/profiles.mjs`：rk=arm64/glibc（y02-1/orange）、cvis=armv7/glibc（coco/plum）、rka=armv7/uClibc（y09/y09p）。
- 单包库物料在 `native/libs/<架构>-<代号>/`；`ui/libs/` 只是构建暂存，**不要手改**。
- 组合包需要 zig `objcopy`（默认 `../_ref/zig/z/zig.exe`）；当前工作区无 `_ref/`，组合包构建会失败——单包不受影响。
- so 预检不可随意 `--skip-so-check`：固件按包内 `.so` 的 libc 类型识别机型系列。
- 构建不要与静态检查并行（构建会重写生成物，检查可能读到中间态）。
- 构建产物：`rk/<appid>.<版本>-rk.amr`、`cvis/...`、`rka/...`；包体目标 < 10MB（组合包硬校验）。

## 十一、黑屏 / 白屏防护清单（新增代码逐项自查）

- [ ] 没有在 `.vue` / 业务模块里静态 import 原生模块；
- [ ] 所有原生调用有 `try/catch` 或能力探测；
- [ ] 所有外部数据（存档、HUD、结算）都可能为 `null`，有兜底；
- [ ] sprite 缺 key 时用占位方块，不抛异常；
- [ ] 音效缺文件时静默跳过，不阻塞游戏；
- [ ] 页面 `onShow` / `onHide` 逻辑独立 `try/catch`；
- [ ] 定时器在 `onUnload` 释放；
- [ ] 循环内不创建大对象、不每帧 `JSON.stringify`；
- [ ] Canvas 指令在允许列表内；
- [ ] 生成物没有手改。
