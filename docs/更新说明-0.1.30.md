# 笔上元气骑士 0.1.30 更新说明

本次更新重点修复战斗表现与结算体验，并补齐存档、引导和调试功能。

## 重点更新

1. **环形弹幕修复**
   - 环形弹幕改为与三发扇形子弹完全相同的普通子弹生成路径。
   - 子弹恢复普通大小，360° 等距发射，不再出现挤在 Boss 身上、飞不出去或缺段的问题。

2. **小怪卡墙修复**
   - 所有敌人生成前检查碰撞，卡墙时自动寻找最近空地。
   - 战斗中若小怪被挤进墙里，会立即拉回可通行区域。
   - 覆盖开局房、普通房、精英房、Boss 召唤物。

3. **结算页显示修复**
   - 左栏「本局战绩」、右栏「宝石结算 / 最佳记录」改为独立滚动，左右内容不再互相挤占。
   - 结算页底部三个按钮固定可见，不再被裁切。
   - 结算页同样屏蔽系统左滑退出，避免误触离开。

4. **难度与射速平衡**
   - 玩家射速回调到上一版参数。
   - 敌人攻击冷却整体缩短，弹幕压力提高。
   - 单局改为 6 层、每层 6～8 房间，缩短单局时长；敌人 HP、伤害、移速随层数成长。

5. **局内存档**
   - 每层起点自动保存检查点。
   - 大厅新增「继续冒险 · 第 X 层」入口。
   - 暂停菜单新增「保存并退出」，下次从本层入口继续，角色、武器、天赋、金币与血量比例保留。

6. **出口引导**
   - 房间清空、门开启后，角色脚下出现金色虚线指向最近出口。
   - 出口上方显示光柱与「出口 / 传送门」文字，不再满地图找门。

7. **调试模式**
   - 设置页新增「调试模式 · 锁血」开关。
   - 开启后新开一局角色不会掉血，关闭后恢复正常。

## 其他调整

- 木箱、木桶、宝箱可被子弹直接打破，减少贴脸交互时间。
- 游戏内与结算页均屏蔽左滑退出。
- UI 继续使用 vh/vw 适配，角色属性百分比与首页按钮文字保持完整显示。
- 三平台安装包同步更新：RK、CVI、A 系列。

## 更新方式

- 已安装旧版本的设备：打开游戏，在大厅按提示更新。
- 新设备：安装对应平台最新安装包。
