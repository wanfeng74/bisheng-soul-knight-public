# 维基重做 · 第一批数据层

## 目标

按 [元气骑士中文维基](https://yqqs.huijiwiki.com/wiki/%E9%A6%96%E9%A1%B5) 重建内容；所有贴图使用自行生成的原创像素素材，不使用原版图片。

## 结构

- 4 大关，每大关 5 小关；
- 每大关第 5 小关为首领房；
- 3-5 后通关；4-5 为扩展关；
- 场景按维基随机抽取，同一大关 5 小关使用同一场景。

## 批次

1. 数据层与 4 大关框架
2. 第一大关：冰原 / 森林 / 遗迹 / 机械遗迹
3. 角色、初始武器、技能
4. 武器库
5. 第二大关
6. 第三、四大关
7. 天赋、雕像、宠物、NPC、成就

## 数据文件

- `data/wiki/chapters.json`：4 大关与场景表
- `data/wiki/chapter1.json`：第一大关小怪/首领清单（待补数值）
- `scripts/wiki-check.mjs`：数据完整性检查

## 贴图规范

- 统一像素尺寸与动作帧数；
- 每个角色/怪物使用独立原创造型；
- 色板参考像素地牢风格，但不描图、不拼接原版素材；
- 先占位后替换，占位图也必须为原创生成。
