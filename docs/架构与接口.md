## 0. 项目定位

有道词典笔上的 2D 俯视像素地牢射击，玩法对标《元气骑士》核心体验：

```
大厅选角/升级 → 进入地牢 → 逐房间清怪/开箱/商店 → Boss → 三选一天赋 → 下一层
→ 第 9 层终局 Boss → 结算（宝石/成就/记录）→ 回大厅继续成长
```

技术底座沿用已验证项目「三角洲摸金模拟器」：

- Falcon / POSC 小程序运行时，Vue 2 SFC 子集 + Canvas 2D + QuickJS
- 逻辑宽固定 960，逻辑高按设备物理比例换算（240～576）
- 构建：`node scripts/build-amr.mjs`（三平台单包）；详见 `docs/技术规范/`
- 页面无 `window/document/require` 语义（原生模块只能通过 `native-mods.js`）

## 1. 运行时红线（会白屏/黑屏的坑）

1. **游戏逻辑模块一律 ES5 风格**：`var` / `function` / 原型，禁止箭头函数、模板字符串、
   `let/const`、解构、可选链、`Array.prototype.includes`、`Object.assign`。
   数据与美术模块同理（它们是打进 QuickJS 包的源码）。
2. **Canvas 能力受限**：只用 `fillRect` / `fillText` / `save` / `restore` / `translate` /
   `rotate` / `scale` / `setTransform` / `globalAlpha` / `fillStyle`。
   **禁止** `arc` / `strokeRect` / `beginPath` / `createLinearGradient` / `textBaseline`。
   圆角/圆形全部用像素块拼。
3. 不给 Canvas 建离屏 canvas（无 `document.createElement`）；静态地图可用
   `createImageData/putImageData`，但必须像旧引擎一样做能力探测 + fallback。
4. 页面生命周期钩子写在 `methods` 里；`onShow/onHide` 内逻辑独立 `try/catch`。
5. 游戏循环用 `setInterval(16ms)`（页面托管），**不要用 requestAnimationFrame**。
6. 熄屏/切后台判断读 `$falcon.__gameHidden`（由 `app.js` 写），不能只依赖页面 onHide。
7. 所有文档、注释、UI 文案一律中文。
8. 不在客户端写服务器地址/密钥；本作**纯单机**，排行榜只做本地记录。

## 6. 引擎（Lead）对外 API

`ui/src/pages/game/game.vue` 只会调用下面这些：

```js
import { Game } from '../../services/game/engine.js'

var g = new Game(ctx, {
  onEndRun: function (result) {},   // 结算回调（只会调一次）
  sfx: function (name) {}           // 引擎内音效出口
})
g.setCanvasPixels(physW, physH)     // canvas 后备缓冲物理像素
g.setViewport(960, pageH)           // 逻辑视口
g.startRun({
  characterId: 'knight',
  upgrades: db.charUpgrades['knight'] || {},
  seed: Date.now(),
  settings: db.settings,
  difficulty: 1
})

g.setMove(dx, dy)                   // -1..1 摇杆
g.setFire(held)                     // 按住开火
g.pressSkill()                      // 技能
g.pressSwap()                       // 换武器
g.pressInteract()                   // 开箱/拾取/商店/雕像
g.pause() / g.resume()
g.update(dtMs)                      // 主循环
g.render()                          // 每帧绘制（内部 setTransform 适配物理像素）
g.getHud()                          // HUD/弹窗快照（见下）
g.chooseBuff(index)                 // 天赋三选一
g.buyShop(index) / g.closeShop()
g.revive() / g.declineRevive()
g.abandonRun()                      // 暂停页放弃
g.destroy()

g.ended                             // bool
```

`getHud()` 返回（纯数据，供 DOM 弹窗/调试）：


## 7. 页面约定

- `index/index.vue` 大厅：标题、宝石、选中角色立绘/属性/技能、开始按钮、角色/图鉴/设置入口、
  最佳记录面板；`$falcon.navTo('game')` 启动；`lastChar` 记忆。
- `characters`：8 角色卡片（未解锁显示费用、点击解锁扣宝石）；选中后显示升级面板
  （6 项，各 0..5 级，显示费用，`+` 扣宝石并保存）；开始冒险按钮。
- `codex`：武器/敌人/成就三 tab，滚动列表，未解锁武器灰色 + 锁定图标。
- `settings`：音效/自动瞄准/震屏/FPS 开关、重置存档（二次确认）、关于（版本/构建/平台/存储/屏幕）。
- `result`：胜负标题、本局统计、新纪录、宝石结算、成就解锁提示、再来一局/回大厅。
- `game`：canvas + DOM 触摸层（摇杆区、开火/技能/换枪/交互/暂停）+ 弹窗（暂停/天赋/商店/复活/
  层介绍）+ 结算跳转；所有弹窗数据来自 `getHud()`，不要自己算游戏数值。

页面之间数据：`$falcon.__gameRun`（开局参数，含 characterId/seed）、
`$falcon.__gameResult`（结算数据）、`$falcon.__gameDb`（当前存档）。
