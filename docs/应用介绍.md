# 笔上元气骑士

## 一句话介绍

一款为触控笔设备打造的像素 Roguelike 地牢冒险：选角色、闯六层、捡武器、叠天赋、击败 Boss。

## 游戏简介

《笔上元气骑士》是一款单机像素地牢游戏。从大厅选择角色进入地牢，逐房间清理敌人、打开宝箱、逛商店、挑战精英怪与首领；每层结束后三选一天赋，让本局越打越强。局内获得的金币与宝石可带回大厅，用于解锁新角色、永久升级和收集图鉴。

游戏针对小屏与触控操作做了适配：左侧摇杆移动，右侧自动开火，支持双指同时移动与射击；也可以开启辅助瞄准，单手轻松游玩。每层自动保存检查点，退出后可从本层起点继续冒险。

## 核心特色

- **六层三章**：森林遗迹、沙海地宫、霜寒王座，每章两种楼层，单局约 6～10 分钟。
- **8 名角色**：骑士、法师、刺客、炼金术士、精灵、工程师、圣骑士、游侠，各自拥有独立技能与成长方向。
- **43 把武器**：手枪、步枪、霰弹、弓弩、法杖、近战等 10 类武器，6 档品质，支持双武器切换。
- **33 种天赋**：伤害、射速、暴击、元素、吸血、召唤、经济等方向自由组合，每局 Build 不重样。
- **18 种小怪 + 4 个 Boss**：追击、远程、冲锋、炸弹、召唤、钻地、飞行等行为，Boss 拥有多阶段弹幕。
- **随机地牢**：每层 6～8 个房间，战斗、精英、宝箱、商店、雕像、Boss 房随机生成，同种子可复现。
- **局内成长**：清怪掉落金币与宝石，商店买武器/药水/天赋，雕像祈福，Boss 后三选一天赋。
- **局外成长**：宝石解锁角色、升级生命/护甲/能量/暴击/移速/技能，图鉴与成就长期收集。
- **触控优化**：左侧虚拟摇杆、右侧持续开火、技能/换枪/交互独立按钮，支持双指操作与辅助瞄准。
- **完全离线**：无需联网即可完整游玩，适合通勤、课间和碎片时间。

## 操作说明

- **移动**：按住屏幕左下方任意位置出现摇杆，拖动移动。
- **攻击**：角色自动瞄准并持续开火；右侧可切换自动开火。
- **技能**：点击底部技能按钮，冷却结束后释放角色技能。
- **换枪**：点击武器槽或换枪按钮，在两把武器间切换。
- **交互**：靠近宝箱、武器、商店、雕像、传送门时点击「交互」。
- **暂停**：点击右上角暂停按钮，可继续、开关辅助瞄准、保存并退出或放弃本局。
- **双指**：左手移动、右手开火，可同时进行。
