## 一、评分规则

### 1.1 状态定义

| 状态 | 含义 | 得分 |
|---|---|---|
| **已实现** | 有代码 + 自动化测试/可复现命令通过，结论可核对 | 权重 × 100% |

| **未实现** | 没有对应实现，或功能不可用 | 0 |

1. **自动化测试输出**（`ui/scripts/test-*.mjs`，可复现命令）；
2. **代码路径**（文件 + 行为描述，必要时给行号）；
3. **构建/资源产物**（`.amr`、PNG、WAV 的路径、体积、时间）；
4. **真机日志/截图**（当前**没有**，所有真机项按「待真机」折算 85%）。
